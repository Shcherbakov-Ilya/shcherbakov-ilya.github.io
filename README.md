# Сайт Ильи Щербакова — публикация на GitHub Pages

## Структура

```
/
├── .nojekyll
└── index.html          ← главная страница (сайт-визитка)
```

Страница полностью самодостаточна: фото и все изображения зашиты прямо в HTML (base64),
внешних файлов не требует. Единственная внешняя зависимость — шрифты Google Fonts.

## Важно: SpecMate — отдельный репозиторий, его не трогаем

SpecMate уже опубликован отдельно, в репозитории `SpecMateAI`, и живёт на
`https://shcherbakov-ilya.github.io/SpecMateAI/`. Это отдельный сайт в отдельном репозитории —
папку с его копией в этот архив специально не кладу, чтобы не плодить рассинхронизированный
дубликат. Ссылка «Смотреть проект →» на главной странице ведёт прямо на его настоящий адрес.

Значит публикация этой папки в корневой репозиторий `shcherbakov-ilya.github.io`
никак не затронет `SpecMateAI` — они физически не пересекаются.

## Как опубликовать

1. В репозитории `shcherbakov-ilya.github.io` (корневой, зарезервированный под этот лендинг)
   залить `index.html` и `.nojekyll` в корень ветки `main`.
2. Убедиться, что в Settings → Pages источник — ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт будет на `https://shcherbakov-ilya.github.io/`.

Если в этом репозитории уже что-то лежит в корне — `index.html` перезапишет только файл
с этим именем, остальное не тронет. Если сомневаешься — можешь сначала посмотреть содержимое
репозитория (`git clone` или через веб-интерфейс GitHub), прежде чем заливать поверх.

## Метрика

Счётчик Яндекс.Метрики для главной — отдельный от SpecMate, но сейчас в коде стоит заглушка
`12345678` (три места в `<head>` + одно в `<noscript>`). Замени на реальный номер счётчика
после того как создашь его в Яндекс.Метрике — либо пришли мне номер, я подставлю сам.

Цели, которые уже расставлены на странице: `cta_header`, `cta_hero`, `hero_services`,
`project_specmate`, `task`, `consult`, `partnership`, `contact_telegram`, `contact_phone`,
`contact_email`, `any_contact`, `theme_dark`/`theme_light`, `scroll_25/50/75/100`,
`view_<секция>` (hero/about/services/projects/credentials/channels/contact), `read_30s/1m/3m`.

## Личный сайт-резюме

`ilya_scherbakov_site.html` («финансовый дневник») в архив не включён — ты говорил, что
пока рано его публиковать. Когда решишь публиковать — обсудим, где он должен жить
(например, `shcherbakov-ilya.github.io/about/` — тоже отдельная подпапка корневого репозитория,
без конфликта со SpecMate).
